# Lumen フォトエディタ

ブラウザだけで動く軽量フォトエディタです。ビルド不要、`index.html` 1 ファイルで完結しています。

## 機能

- レイヤー：追加・複製・削除・並べ替え・下と結合・統合、不透明度、描画モード 16 種
- ツール：移動 (V)、長方形選択 (M)、ブラシ (B)、消しゴム (E)、塗りつぶし (G)、スポイト (I)、テキスト (T)、シェイプ (U)、手のひら (H)、ズーム (Z)
- フィルター：明るさ・コントラスト、色相・彩度、ぼかし（ガウス）、シャープ、ポスタリゼーション、モノクロ、セピア、階調の反転
- イメージ：画像サイズ、選択範囲で切り抜き、90° 回転、反転
- ヒストリー：最大 30 ステップ、一覧から任意の時点へ戻れます
- 入出力：開く／ドラッグ＆ドロップ／貼り付けで読み込み、PNG・JPEG・WebP で書き出し

## 主なショートカット

| 操作 | キー |
| --- | --- |
| 取り消し／やり直し | Ctrl+Z ／ Ctrl+Shift+Z |
| ブラシサイズ | [ ／ ] |
| 一時的に手のひら | Space を押しながらドラッグ |
| ズーム | Ctrl+ホイール、Ctrl+0（全体表示）、Ctrl+1（100%） |
| 選択解除 | Ctrl+D |
| 描画色と背景色の入れ替え／初期化 | X ／ D |

## GitHub Pages で公開する

1. このフォルダの中身をリポジトリのルートに置いて push します。
2. リポジトリの **Settings → Pages** を開きます。
3. **Source** を「Deploy from a branch」、ブランチを `main`、フォルダを `/ (root)` にして保存します。
4. 1〜2 分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます。

ローカルで試す場合は `index.html` をブラウザで開くだけで動きます。
