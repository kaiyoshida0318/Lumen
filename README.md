# Lumen フォトエディタ

ブラウザだけで動く、Photoshop 風の軽量フォトエディタです。ビルド不要、`index.html` 1 ファイルで完結しています（PSD の読み書き時だけ [ag-psd](https://github.com/Agamnentzar/ag-psd) を CDN から読み込みます）。

## 機能

- **ドキュメント**：複数ファイルをタブで切り替え、未保存の変更は `*` で表示。閉じるときに確認
- **ファイル**：画像（PNG・JPEG・WebP・GIF など）と PSD を開く、PSD で保存（レイヤー・不透明度・描画モード・表示状態を保持）、PNG / JPEG / WebP で書き出し
- **テキストレイヤー**：文字のまま保持し、クリックで再編集。書体 8 種（ゴシック・丸ゴシック・明朝・等幅ほか）、太字・斜体、サイズ、色、左・中央・右揃え、縦書き、行送り、字送り、下線・取り消し線、境界線。移動や拡大縮小では文字のまま、ブラシやフィルターをかけると自動でラスタライズ。PSD の文字レイヤーとして保存・読み込み
- **ツール**：移動、長方形・楕円形選択、なげなわ・多角形選択、自動選択・クイック選択、切り抜き、ブラシ、消しゴム、グラデーション、塗りつぶし、スポイト、テキスト、シェイプ、手のひら、ズーム
- **選択範囲**：追加・削除・共通範囲、反転、境界をぼかす、再選択、選択範囲の移動、レイヤーの不透明部分を選択
- **編集**：自由変形（拡大縮小・回転・反転）、カット／コピー／結合部分をコピー／ペースト、塗りつぶし、消去
- **レイヤー**：新規・複製・選択範囲をコピー／カットしたレイヤー・削除・ドラッグで並べ替え・下と結合・表示レイヤーを結合・統合、不透明度、描画モード 16 種、Alt+目のアイコンで単独表示
- **イメージ**：明るさ・コントラスト、色相・彩度、彩度を下げる、階調の反転、ポスタリゼーション、セピア、画像解像度、カンバスサイズ、画像の回転・反転
- **フィルター**：ぼかし（ガウス）、シャープ
- **ヒストリー**：ドキュメントごとに最大 30 ステップ

## ショートカット（Photoshop と同じ配置）

| 操作 | キー |
| --- | --- |
| ツール | V 移動 / M 選択（Shift+M で長方形・楕円形） / L なげなわ（Shift+L で多角形） / W 自動選択（Shift+W でクイック選択） / C 切り抜き / B ブラシ / E 消しゴム / G グラデーション（Shift+G で塗りつぶし） / I スポイト / T テキスト / U シェイプ / H 手のひら / Z ズーム |
| 開く・保存・書き出し | Ctrl+O / Ctrl+S（PSD） / Alt+Shift+Ctrl+W |
| 取り消し・やり直し | Ctrl+Z / Shift+Ctrl+Z |
| カット・コピー・結合部分をコピー・ペースト | Ctrl+X / Ctrl+C / Shift+Ctrl+C / Ctrl+V |
| 自由変形 | Alt+T（全画面表示中は Ctrl+T）、右クリックメニューからも可。Enter で確定、Esc でキャンセル |
| 全画面表示 | F（Chrome ではこの間 Ctrl+T・Ctrl+W・Ctrl+N・Ctrl+Tab をエディタ側で使えます。Esc 長押しで終了） |
| 選択 | Ctrl+A すべて / Ctrl+D 解除 / Shift+Ctrl+D 再選択 / Shift+Ctrl+I 反転 / Shift+F6 境界をぼかす |
| 選択の追加・削除・共通 | Shift / Alt / Shift+Alt を押しながら選択 |
| レイヤー | Ctrl+J 選択範囲をコピーしたレイヤー / Shift+Ctrl+J カットしたレイヤー / Ctrl+E 下と結合 / Shift+Ctrl+E 表示レイヤーを結合 / Ctrl+[ ] 重ね順 |
| 色調補正 | Ctrl+U 色相・彩度 / Shift+Ctrl+U 彩度を下げる / Ctrl+I 階調の反転 |
| サイズ | Alt+Ctrl+I 画像解像度 / Alt+Ctrl+C カンバスサイズ |
| 塗りつぶし・消去 | Alt+Delete 描画色 / Ctrl+Delete 背景色 / Delete 消去 |
| ブラシ | [ ] サイズ / Shift+[ ] 硬さ / 数字キーで不透明度（他のツールではレイヤーの不透明度） |
| 表示 | Space+ドラッグで移動 / Ctrl・Alt+ホイールでズーム / Ctrl+0 画面サイズ / Ctrl+1 100% |
| 移動ツール | 矢印キーで 1px（Shift で 10px） / Alt+ドラッグで複製 / Ctrl+クリックでレイヤーを選択 |
| 色 | X 入れ替え / D 初期設定 |

Ctrl+T・Ctrl+N・Ctrl+W・Ctrl+Tab はブラウザが先に使うため、通常表示では効きません。自由変形は Alt+T、それ以外はメニューとタブから操作するか、F キーで全画面表示にすると Photoshop と同じキーで使えます。

## GitHub Pages で公開する

1. このフォルダの中身をリポジトリのルートに置いて push します。
2. リポジトリを Public にし、**Settings → Pages** で Source を「Deploy from a branch」、ブランチを `main`、フォルダを `/ (root)` にして保存します。
3. 1〜2 分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます。

ローカルで試す場合は `index.html` をブラウザで開くだけで動きます。
